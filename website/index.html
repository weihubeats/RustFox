常见问题

更多见 用户手册 FAQ。

macOS 提示「已损坏，无法打开」？

应用本身没有损坏，这是 Gatekeeper 对未公证应用的拦截。拖入「应用程序」后执行 xattr -cr /Applications/RustFox.app，再右键 → 打开。

Windows SmartScreen 警告？

点击「更多信息 → 仍要运行」。安装包暂无代码签名证书，开源项目正常现象。

环境变量显示乱码？

数据目录的 master.key 丢失导致无法解密。用备份 JSON 恢复（设置页 → 恢复）。

MCP 报 spawn ENOENT？

二进制不在 PATH。v0.0.10+ 安装包填写包内绝对路径（macOS 如上 agent 章节），不要写裸 rustfox-mcp。

dev 构建看不到正式版数据？

符合预期：dev 使用 RustFox-dev 目录隔离。用备份 JSON 在两侧互导。

如何反馈问题？

顶栏「反馈」按钮生成本机诊断报告，附到 GitHub Issues 即可。
