请求与编辑

8 种 HTTP 方法、6 种请求体格式；cURL 一键粘贴导入；环境变量 {{name}} 全局自动解析。

🔐

认证与安全

API Key / Basic / Bearer / OAuth2 四模式；环境变量值 AES-256-GCM 加密存储。

🧪

Mock Server

本地 axum Mock，端口自动探测无需联网；规则匹配优先，模板变量渲染动态响应。

✅

自动化测试与压测

JSON 测试脚本：注入变量、提取传递、断言；压测输出 QPS 与 P50/P90/P99 图表。

🔄

导入导出

OpenAPI 3.x / Swagger 2.0 / Postman v2.1 互通；导出 Markdown 文档与多语言客户端代码。

🔒

本地优先

数据只存在本机 rustfox.db，一键备份为 JSON 随时恢复，数据始终在你手里。
